# GrowBox — премиальный гроушкаф (проект v3.0 / v3.1 rev.2)

Тихий шкаф-гроубокс на 2 растения (SCROG) с полной автоматикой Spider Farmer GGS.
Принцип проекта: *выглядит как мебель · звучит как тишина · работает как швейцарские часы*.

**Габариты:** 1250 × 700 × 2000 мм · **Зона растений:** 796 × 620 мм (~0,49 м²) · **Свет:** SE3000 (300 Вт) на актуаторе · **Тишина:** вентиляция Ø100 с шумоглушителем и виброподвесами

## 💻 Локальная сборка на своём ПК (Windows)

Чтобы не скачивать готовые файлы, а пересобирать модель под свои размеры:

1. Установи [Python 3.12](https://python.org/downloads/) — **с галочкой «Add python.exe to PATH»**
2. Склонируй репозиторий (или скачай ZIP: кнопка `Code → Download ZIP`)
3. В папке проекта запусти `setup.ps1` (правой кнопкой → Run with PowerShell) — поставит CadQuery
4. Запусти `build.bat` — модель пересоберётся, файлы обновятся в `models/v3.1/`

Чтобы поменять размеры: открой `models/v3.1/build_v31_modular.py`, блок параметров `P = dict(...)`
в начале (ширины модулей, толщины ЛДСП, габариты оборудования) → сохрани → `build.bat`.
Протокол проверок габаритов — `models/v3.1/reports/fit_check.txt`.

## 🔧 Ключевые решения v3.0

- **Свет:** SE3000 (603×585×71, PPF 856) — встаёт в зону с зазорами 96 мм по бокам; SE4500 снят (не влезает). Дополнительно UV30/IR16, зелёная подсветка 520–540 нм, актуатор подъёма 12 В (ход 300 мм).
- **Вентиляция:** лабиринт-приток → угольный фильтр SF 4" → вентилятор SF 4" (виброподвесы) → шумоглушитель → решётка 400×300 в комнату. Рабочие 80–135 м³/ч при объёме зоны 0,97 м³, разрежение обязательно.
- **Автоматика:** GGS Controller + 2× AC10 (20 розеток), ESP32, автодозатор A/B/микро + pH-модуль, перистальтика, компрессор аэрации, ИБП 600 ВА, Wi-Fi камера, датчик протечки, Soil Sensor Pro.
- **Корпус:** ЛДСП 18 мм, мокрая зона — фанера 18 + моющееся покрытие; раскладка по ширине 18+400+18+796+18 = 1250 мм. Раскрой укладывается в 2 листа 2800×2070.
