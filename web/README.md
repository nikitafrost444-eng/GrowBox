# Web · интерактивная 3D-модель GrowBox v3.1

Каноническая веб-страница с 3D-моделью шкафа. Геометрия **не нарисована на глаз** —
она сгенерирована из параметрической сборки `models/v3.1/build_v31_modular.py`
(те же 85 деталей, те же размеры, зазоры и петли).

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Основная страница: полный 3D, двери/ящики/газлифты, разрез, выбор деталей |
| `viewer_mobile.html` | Компактный просмотрщик под телефон (та же геометрия) |
| `model_parts.js` | Данные модели: 85 деталей (bbox, цвет, тип) из CAD |
| `vendor/three.min.js` | Three.js r128 (UMD, работает офлайн и с `file://`) |

## Как открыть

Просто открой `index.html` в браузере (двойной клик). Интернет не нужен —
библиотека и данные лежат рядом со страницей.

## Что можно делать

- **Вращать** — ЛКМ / пальцем, **зум** — колесо / щипок, **сдвиг** — Shift+ЛКМ
- **Открыть двери** — три створки-сэндвича вращаются вокруг реальных петель:
  дверь B — левый край (x=0), створка C1 — x=437 мм, створка C2 — правый край (x=1250)
- **Выдвинуть ящики** — бак, сервисный ящик, секрет-бокс (ход 450 мм)
- **Поднять фасады** — модули A и B на газлифтах, петля по верхней кромке (z=1700 / 2000)
- **Разрез** — корпус и фасады полупрозрачные, видно начинку
- **Свет SE3000** — подсветка камеры роста
- **Клик по детали** — название, модуль, габариты и описание

## Система координат

Данные в `model_parts.js` — в миллиметрах, в координатах CAD:
`X` — ширина 0…1250, `Y` — глубина 0…700 (0 — плоскость фасада), `Z` — высота −60…2000.
Просмотрщик пересчитывает их в метры и сдвигает центр в начало координат.

## Как обновить геометрию

1. Поменяй параметры в `models/v3.1/build_v31_modular.py` (блок `P = dict(...)`)
2. Пересобери модель (`build.bat` / `python build_v31_modular.py`)
3. Сгенерируй `model_parts.js` заново из сборки (та же функция экспорта bbox)
4. Обнови страницу — все размеры подтянутся автоматически

## Проверено

- Пропорции 1250×700×2000 (ширина < высота), модули A/B/C на своих местах
- Двери открываются наружу вокруг своих петель, ящики выезжают наружу, фасады поднимаются
- Работает из `file://` без интернета (three.js UMD подключён локально)
