# v3.1 — двухкамерный шумоглушитель SF 4" (своими руками)

**Статус:** рабочее предложение к v3.1 (обсуждение 28.09.2026) · **Чертёж:** [`drawings/silencer-v3.1.svg`](drawings/silencer-v3.1.svg)
**Заменяет:** покупной глушитель Ø180×300 из схемы акустического модуля.

---

## 1. Идея

Не «короб с ватой», а **канальный глушитель**: воздух идёт по центральному каналу,
вокруг — звукопоглощающий слой за перфорированным экраном. Две камеры с шейкой между
ними дают два принципа гашения сразу:

- **Диссипативный** (камера 1 и 2): минвата за перфорацией гасит средние и высокие частоты;
- **Реактивный** (шейка Ø120 между камерами + расширения): добавляет низкие частоты,
  где вата слаба (а именно там гудит мотор и лопасти).

Ожидаемое затухание **15–20 дБ(А)** — больше, чем у одного длинного глушителя той же длины.

## 2. Конструкция

| Узел | Решение |
|---|---|
| Корпус | ЛДСП/фанера **18 мм**, стыки на герметике (звук любит щели) |
| Поглотитель | Минвата HVAC 30–50 кг/м³ **в обойме** (стеклоткань/фольга), класс НГ/КМ0 |
| Канал | Перфорированный экран 8 мм (оргалит/оцинковка): отв. 4–5 мм, шаг 8–10, открытая площадь 25–30% |
| Камеры | ≈280 / ≈240 мм, между ними перегородка с шейкой Ø120 |
| Крышка | **Съёмная** (винты М6) + уплотнительная прокладка по фланцу |
| Вход/выход | Фланцы Ø100 → гибкие вставки 100 мм с хомутами с обеих сторон |

**Габарит (предварительно):** 650 × 280 × 280 мм, масса ~12–15 кг.
Канал внутри: 160×160 мм.

## 3. Цифры

| Параметр | Значение |
|---|---|
| Площадь канала 160×160 | 256 см² |
| Скорость в канале (рабочие 80–135 м³/ч) | 0,9–1,5 м/с |
| Скорость в канале (макс 220 м³/ч) | 2,4 м/с |
| Скорость в шейке Ø120 (макс) | ~5,4 м/с (локально, короткий участок) |
| Сопротивление глушителя | **≤10 Па** (не главное сопротивление системы) |
| Затухание | 15–20 дБ(А) |

Для сравнения: в «родном» канале Ø100 на максимуме скорость 7,8 м/с — там шум потока
заметен. Расширение канала внутри глушителя — главный вклад в тишину.

**Проверка по системе (без изменений):** фильтр 30–50 Па + глушитель ≤10 Па + прочее ≤10 Па
≈ **≤70 Па** — бюджет из схемы модуля держится.

## 4. Правила, которые не нарушаем

- ❌ Открытый поролон в канале — нет (пыль/волокна, пожарный риск). Только HVAC-материал
  с защищённой поверхностью за перфорацией.
- ❌ Короб не вешаем на воздуховод и не крепим жёстко к стенкам — своя полка/кронштейны,
  с обеих сторон гибкие вставки (развязка).
- ❌ Без прокладки под крышкой не работает: звук утечёт мимо поглотителя через щель.
- ✅ Ревизия раз в 6–12 мес: снять крышку, проверить поглотитель (в зоне растений пыльца
  и пыль от грунта неизбежны).
- ✅ Конденсат: тёплый влажный воздух из зоны — держим глушитель внутри тёплого модуля,
  при ревизии осматриваем торцы.

## 5. Влияние на компоновку модуля (важно!)

Прежний ряд «фильтр 400 + вставка 100 + SF4 280 + вставка 100 + глушитель 300» укладывался
в 1250. С глушителем 650 ряд становится **1530 мм — не влезает**. Два решения:

**Вариант А (рекомендую): змейка в две строки по глубине 700.**
- Передний ряд (глубина ~300): фильтр — вставка — SF4 (ось по ширине), ≈780 мм.
- Задний ряд (глубина ~300): глушитель 650 (ось по ширине) + выход в пленум и решётку.
- Разворот 90° между рядами — гибкая вставка + крупный отвод, сопротивление ≤5 Па.
- 2 строки × 300 = 600 < 664 внутренней глубины. Всё в одном верхнем модуле.

**Вариант Б: фильтр возвращается под потолок зоны растений** (как в v3.0),
ряд модуля: SF4 + вставка + глушитель 650 = 1030 мм — свободно. Минус: фильтр в рабочей
зоне, доступ через дверь; плюс — проще монтаж.

## 6. Сборка (порядок)

1. Короб 650×280×280 (18 мм), герметик по стыкам.
2. Перегородка с шейкой Ø120.
3. Экран перфорированный (короб канала 160×160) с обеих сторон перегородки.
4. Минвата 40 мм в обойме — заполнить полости вокруг канала, без зазоров и без уплотнения «в пресс».
5. Крышка на винтах М6 + прокладка.
6. Фланцы Ø100, обжим хомутами на гибких вставках; короб — на собственной полке.

## 7. Следующие шаги

1. Уточнить фланцы SF4/фильтра (факт) → финальные размеры корпуса и шейки.
2. Внести узел в 3D-модель v3.1 (вариант А компоновки).
3. Опционально: вторая шейка/камера при недостаточном затухании (есть резерв по длине 700).
