# Сессия 2026-10-01 — CAD v3.1 rev.2: модульная параметрическая модель

## Что сделано

1. **Установлено CAD-ядро**: Python 3.12 + CadQuery 2.8.0 (OpenCASCADE 7.9) — генерация STEP/DXF/STL
   без нативного КОМПАС. Нативные `.m3d/.a3d/.cdw` создаются только в КОМПАС-3D — см.
   `docs/kompas_import_v3.1.md` (пошаговый импорт STEP → сборка/детали).
2. **Собрана параметрическая модель v3.1 rev.2** (`models/v3.1/build_v31_modular.py`) под модульную
   архитектуру из ТЗ (pdf/growbox_v31_rev2.pdf):
   - модуль A — верхний акустический техмодуль 300 мм: фильтр SF4 → вентилятор → глушитель → пленум →
     решётка 400×300;
   - модуль B — тех-колонна 400 мм: ящик бака 20 л, сервисный ящик, секрет-бокс (увлажнитель),
     DIN-панель (GGS + 2×AC10 + ИБП), полка резервного бака с рамой 30×30;
   - модуль C — камера роста 796 мм: EVA-поддон, выкатная платформа, 2 горшка 15 л, SCROG V-рамка
     (4 уровня), SE3000 + UV/IR на роликовых подвесах, SensorPro.
3. **Экспорт**: 28 отдельных деталей STEP + полная сборка STEP (+ STL), 20 DXF развёрток,
   `csv/cutlist.csv` (карта раскроя), `csv/bom.csv` (ведомость), 4 SVG-превью,
   `reports/fit_check.txt`.

## Закрытые проверки (раздел 13 ТЗ)

- ① BBox и размеры модулей зафиксированы: B 400×600×1700, C 796×600×1700, A 1250×700×300
- ② Тракт в 300 мм модуля A: макс. Ø250 при внутр. 282 мм — **PASS** (запас 32 мм, учесть виброподвесы)
- ③ Направляющие платформы: мокрые горшки ~50 кг → Tandem 500, запас ≥1,5 (75 кг)
- ④ Сервисный канал 80 мм (фанера 12 + оргалит 8), гермовводы PG-13.5/PG21
- ⑥ SE3000: зазоры ±96 мм по X, **±7,5 мм по Y** — узкое место, проверить по фактической ревизии
- ⑦ Дренаж/автодолив: поддон EVA + поплавок 3/4"

## Решения по геометрии (расхождения ТЗ → CAD)

- Глубина: канон «сервисный канал 80–100» закрыт на нижней границе **80 мм**:
  зона 600 + фанера 12 + канал 80 + оргалит 8 = 700. В ТЗ карта раскроя давала перегородку 620 —
  пересчитано под 600 (сумма с каналом 80 не влезала в 700).
- Высота модулей B+C принята 1700 (снизу), модуль A 300 (сверху) = 2000 по канону.
- Фасады стоят в плоскости y=-18…0, габарит с фасадами 718 по глубине.
