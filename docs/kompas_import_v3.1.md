# Импорт модели v3.1 rev.2 в КОМПАС-3D

Файлы в `models/v3.1/step/` и `models/v3.1/dxf/` сгенерированы как **открытые форматы** (STEP AP214 + DXF).
Нативные форматы КОМПАС (`.m3d` деталь, `.a3d` сборка, `.cdw` чертёж) создаются только внутри КОМПАС-3D —
ниже пошаговый переход от STEP к нативным файлам.

## 1. Полная сборка → `.a3d`

1. КОМПАС-3D → **Файл → Открыть** → выберать тип файла **STEP AP214 (*.stp; *.step)** →
   `models/v3.1/step/growbox_v31_rev2_assembly.step`
2. В диалоге импорта: режим **«Сборка»** (не «Единая деталь»!), структуру сохранять по именам компонентов.
   Имена деталей уже заданы (`01_Боковина_левая_B-C`, `25_SE3000`, …) — они станут именами компонентов.
3. **Файл → Сохранить как** → `growbox_v31_rev2.a3d`.
4. Если КОМПАС предложит «Выполнить пересборку» — согласиться, затем **Сервис → Проверка сборки**
   (поиск помех/зазоров).

Альтернатива: `growbox_v31_rev2_all.step` — тот же объём одним компаундом (если нужна единая деталь для
расчётов/визуализации, а не сборка).

## 2. Отдельные детали → `.m3d`

`models/v3.1/step/parts/` — 28 файлов STEP, каждая деталь отдельно (мебельные панели, ящики, фасады).

1. **Файл → Открыть** → STEP → нужный файл (например `05_Перегородка_B-C_сервисная.step`).
2. КОМПАС откроет его как деталь → **Файл → Сохранить как** → `имя.m3d`.
3. Для каркасных деталей из профиля/труб — после импорта можно применить библиотеки металлопрофиля.

Совет: создайте библиотеку `GrowBox_v31/` и складывайте туда `.m3d`, чтобы сборка `.a3d` ссылалась на
локальные файлы, а не на STEP.

## 3. Раскрой и чертежи → `.cdw`

`models/v3.1/dxf/` — контуры 20 плоских деталей (карта раскроя).

1. **Файл → Открыть** → DXF → деталь (например `10_Дверь_камеры_C.dxf`).
2. Проверьте масштаб: DXF в миллиметрах 1:1, лист модели = реальный размер.
3. Создайте чертёж (`.cdw`), проставьте размеры, допуски, обозначения сверловки/фурнитуры.
4. Для раскроя ЛДСП: карта в `models/v3.1/csv/cutlist.csv` (разделитель `;`, UTF-8) —
   загрузите в оптимизатор раскроя (Cutting, Astra, Excel) перед заказом.

## 4. Именование и структура

| Префикс | Содержимое |
|---|---|
| `01–09` | каркас модулей B+C и опоры |
| `10–15` | фасады и двери (Push-to-Open, Blum) |
| `16–20` | воздуховодный тракт модуля A (фильтр → SF4 → глушитель → пленум → решётка) |
| `21–28` | камера роста C (поддон, платформа, горшки, SCROG, свет, датчики) |
| `29–41` | тех-колонна B (ящики, баки, увлажнитель, DIN-панель, электрика) |
| `42–56` | оборудование/фурнитура (огибающие) |

**Огибающие оборудования** (`kind=оборудование` в `csv/bom.csv`) — упрощённые тела для проверки посадки
и компоновки. Перед закупкой сверьте с реальными габаритами ревизий (чек-лист ⑤ из ТЗ).

## 5. Что проверить после импорта

- [ ] Совпадение габаритов BBox: 1250 × 718 × 2060 (с фасадами и опорами)
- [ ] Зазоры SE3000 в камере: ±96 мм по X, ±7,5 мм по Y (строгий минимум — переделать посадку, если мешает)
- [ ] Тракт в модуле A: Ø250 при внутренней высоте 282 мм — запас 32 мм, учесть виброподвесы
- [ ] Прорези перегородки B/C под гермовводы PG-13.5/PG21
- [ ] Чек-лист ②: габариты конкретных ревизий фильтра/вентилятора/глушителя (план «Б» — фильтр в камеру C)

Протокол автоматических проверок: `models/v3.1/reports/fit_check.txt`.
