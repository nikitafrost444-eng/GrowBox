# 2026-09-27 — Проект «Гроубокс» (3D-модель для КОМПАС)

## Контекст
Пользователь проектирует премиальный гроушкаф (2 растения, SCROG, спальня, тишина как ТЗ).
Есть 2 PDF (v1.0 `Проект_Гроушкаф.pdf` и v2.0 `Гроушкаф_Полное_описание_v2.pdf` — второй собран
Алисой с битой кодировкой кириллицы) + 2 вычитанных чата (Qwen — стратегия/железо, Алиса — модули:
pH с обучением, автодозатор, V-SCROG, зелёная подсветка, ИБП, музыка). Чаты лежат в
`.openclaw/tmp/growbox/` (qwen_chat.txt, alice_chat.txt, выкачанные через headless-браузер).

## Принятые решения (27.09.2026)
1. Свет — **SE3000** (603×585×71 мм, 300 Вт, PPF 856). SE4500 снят: не влезает в зону.
2. Вентилятор — **SF 4"** (Ø100), не 6"; тишину даём изоляцией + шумоглушителем (всё SF, без гибрида S&P).
3. Полный набор автоматики: актуатор 12В подъёма лампы, автодозатор (3 перистальтики + ESP32),
   pH-коррекция, ИБП 600 ВА, зелёная подсветка 520–540 нм, камера, датчик протечки.
4. Габариты канона v3.0: корпус **1250×700×2000**, колонна 400 внутр., зона растений **796×620×1964**,
   колодец 58 мм (раскладка 18+400+18+796+18=1250 — в v2 «450+800+80» не сходилось).

## Сделано
- 3D-модель: `growbox_v3/` — STEP (76 деталей, имена кириллицей через \X2\-эскейпы),
  STL, GLB + viewer.html, цветные рендеры (render_*.png), чертёжные SVG-превью,
  спецификация с картой раскроя (`growbox_v3_spec.md`), исходники (CadQuery 2.8,
  `build_growbox_v3.py`, `render_matplotlib.py`).
- Проверки: BBox 1250×730×2060, визуальный QA через mimo-omni (структура цельная,
  после правок: направляющие SCROG к стенам + кронштейны, датчики в горшках, хомуты фильтра).

## Техзаметки (для будущих сессий)
- STEP-кириллица от OCC приходит двойным UTF-8 (mojibake) — в build-скрипте есть
  `fix_step_unicode()` (latin-1 → utf-8 repair → \X2\-эскейпы).
- Headless Chrome не композит WebGL в скриншоты (model-viewer → пустые PNG) —
  цветные рендеры делаем через matplotlib Poly3DCollection (единый набор полигонов
  для корректной сортировки граней).
- agent-browser: Chrome в `/home/work/.agent-browser/browsers/chrome-154.../chrome`,
  нужен `AGENT_BROWSER_EXECUTABLE_PATH` (системный /opt/ms-playwright без +x).
- Скриншоты agent-browser падают в cwd его сессии (`.openclaw/tmp/growbox/`).
